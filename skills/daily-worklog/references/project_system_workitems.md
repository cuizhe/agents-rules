| 项目立项与排产计划管理

| 招投标管理

| 项目专属招聘支持
	
针对项目特定需求开展招聘（含内部协调），协调面试官，跟踪招聘进度，确保项目人员及时到岗。 | 是 |
| 项目招聘进度跟踪

| 项目面试官安排

| 项目人员入离职与异动管理
	
处理项目内部人员调动、晋升、调薪等异动；跟踪待入职人员风险；处理员工入项材料审核、入职/离职流程、离职面谈。 | 是 |
| 项目新员工融入
	
组织项目新员工入职引导，介绍项目情况、团队文化，帮助新员工快速融入 | 是 |
| 项目人员绩效辅导
	
协助项目经理开展项目成员绩效辅导，提供绩效评估建议，跟踪绩效改进情况 | 是 |
| 项目薪酬福利与成本管控
	
提供项目人员薪酬核算所需信息；测算项目成本率、12+N成本、项目付费率；沟通降薪、薪酬变更、年度贡献奖等事宜；处理员工报销、社保切换等福利问题。 | 是 |
| 项目人员合同管理

| 项目差旅管理

| 闲置/高成本人力处理

| 项目专项培训组织

| 项目团队氛围建设

| 项目人力数据跟踪
	
每日跟踪项目人员到岗、离职、异动数据，在岸离岸人员信息确认，形成项目人力数据报表。 | 是 |
| 项目EHS&CSR管理
	
开展项目人员安全培训，维护EHS档案，确保项目人员安全 | 是 |
| 合规审核
	
审核关联关系、考勤、报销、个人信息真实性、机试、面试、人员岗位匹配度、第二职业以及交付真实性、资产管理等，准确识别出不合规问题，或风险，或不满足要求的流程，必须驳回，对重大问题于4小时内报到内控合规管理部。 | 是 |
| 合规自查
	
自查关联关系、考勤、报销、个人信息真实性、机试、面试、人员岗位匹配度、第二职业以及交付真实性、资产管理等，结果记录到问题清单、问题台账月度例行报内控合规管理部。对重大隐患或风险、问题等，4小时内报于内控合规管理部。 | 是 |
| 合规整改
	
针对问题制定有效的整改措施，明确整改责任人，并推动落地，确保同类问题收敛，管理有效，风险可控。对发现的制度流程类问题，报于内控合规管理部 | 是 |
| 培训赋能
	
例行聚焦客户&公司红线要求，向全员传递&解读客户/公司合规要求及案例。将培训赋能数据、主题等报内控合规管理部。 | 是 |
| 风险人员
	
新员工、离职员工、高权限人员全周期信息安全风险管控，组织安全宣传培训与自检，开展风险识别与日常管理。 | 是 |
| ODC场地访客接待管理
	
负责 ODC 场地访客接待全流程管理，严格审核审批，规范接待过程，全面落实访客相关安全风险管控。 | 是 |
| 资产管理
	
临时资产标签、设备自检、出入场、转移退库等日常安全管理。 | 是 |
| 样机管理
	
测试样机专人保管、保密柜管理、定期盘点及借用归还登记，全程可追溯。 | 是 |
| 机要处置
	
端口加封/拆封、安全机箱/网口盒开锁/关锁等操作。 | 是 |
| 护网开展
	
风险排查与自检整改。 | 是 |
| 日常运维
	
网络设备策略配置、故障处理。 | 是 |
| 风险评估与处置
	
风险场景点灯及风险处置效果验证。 | 是 |
| 安全事件响应和处置
	
安全事件的调查、上报、回溯和闭环、处置和发文等管理活动。 | 是 |
| 其它
	
上述未涵盖的工作 | 是 |

- 客户侧专项汇报

- 收集客户声音

- 客户问题处理及声音闭环
	
推动客户反馈的内部分析与改进，编制VOC分析报告，并向客户澄清与反馈。
- 内外部干系人沟通

- 关键节点评审与过程审视

- 项目质量报告

- 项目内部会议
	
参与项目组内部例会（周例会、迭代会议等），做好会议材料准备等工作。
- AI工具落地与应用支持
	
推动项目AI工具落地应用，评估使用场景与效果，收集并跟踪解决工具使用问题。
- 经验总计及分享

- 人员能力培养及考试认证

- 项目立项与排产计划管理

- 项目成本监控
	
监控项目成本使用情况，分析成本数据，确保成本在预算范围内，识别优化机会。
- 排产与PO运营
	
统筹项目立项与月度排产计划，负责排产数据分析、人力预算及计划评审、加班安排、考勤处理、跟踪PO交付、开票回款与费用预警、同步开展工时检查、产出审核、人力核对及项目分摊。
- 招投标管理

- 项目人力需求分析

- 项目专属招聘支持
	
针对项目特定需求开展招聘（含内部协调），协调面试官，跟踪招聘进度，确保项目人员及时到岗。

定期与招聘部对齐项目人员到位情况及完成情况，发送日报/周报
- 项目面试官安排

- 项目人员入离职与异动管理
	
处理项目内部人员调动、晋升、调薪等异动；跟踪待入职人员风险；处理员工入项材料审核、入职/离职流程、离职面谈。
- 项目新员工融入
	
组织项目新员工入职引导，介绍项目情况、团队文化，帮助新员工快速融入
- 项目人员绩效辅导
	
协助项目经理开展项目成员绩效辅导，提供绩效评估建议，跟踪绩效改进情况
- 项目薪酬福利与成本管控
	
提供项目人员薪酬核算所需信息；测算项目成本率、12+N成本、项目付费率；沟通降薪、薪酬变更、年度贡献奖等事宜；处理员工报销、社保切换等福利问题。

员工合同改签、续签及确认；合同续期、需求清退等。
- 项目差旅管理
	
出差需求对齐、申请、报销材料审核提交、客户侧流程推动等；出差前的信息安全培训等。
- 闲置/高成本人力处理
	
识别项目内的闲置或高成本人力，快速沟通协调转岗或释放，降低项目资源闲置成本。
- 项目专项培训组织

- 项目团队氛围建设

- 项目人力数据跟踪
	
每日跟踪项目人员到岗、离职、异动数据，在岸离岸人员信息确认，形成项目人力数据报表。
- 项目EHS&CSR管理
	
开展项目人员安全培训，维护EHS档案，确保项目人员安全
- 合规审核
	
审核关联关系、考勤、报销、个人信息真实性、机试、面试、人员岗位匹配度、第二职业以及交付真实性、资产管理等，准确识别出不合规问题，或风险，或不满足要求的流程，必须驳回，对重大问题于4小时内报到内控合规管理部。
- 合规自查
	
自查关联关系、考勤、报销、个人信息真实性、机试、面试、人员岗位匹配度、第二职业以及交付真实性、资产管理等，结果记录到问题清单、问题台账月度例行报内控合规管理部。对重大隐患或风险、问题等，4小时内报于内控合规管理部。
- 合规整改
	
针对问题制定有效的整改措施，明确整改责任人，并推动落地，确保同类问题收敛，管理有效，风险可控。对发现的制度流程类问题，报于内控合规管理部
- 培训赋能
	
例行聚焦客户&公司红线要求，向全员传递&解读客户/公司合规要求及案例。将培训赋能数据、主题等报内控合规管理部。
- 风险人员
	
新员工、离职员工、高权限人员全周期信息安全风险管控，组织安全宣传培训与自检，开展风险识别与日常管理。
- ODC场地访客接待管理
	
负责 ODC 场地访客接待全流程管理，严格审核审批，规范接待过程，全面落实访客相关安全风险管控。
