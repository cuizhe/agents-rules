# ten-step-learning — 十步学习法(端到端学习流水线)

> 把大刘《用 Claude/Codex/Workbuddy 10 倍速学习任何知识》里的「十步法」做成一次性可执行的 skill。
> **用户只给主题 → 自动跑完十步 → 产出一个非常详细、DESIGN 合规的单文件学习 HTML**。
> SKILL.md 正文承载**定位、五阶段流程、三栏语义、完成判定**;十步逐字提示词与模板填充规范下沉到 `references/`。

## 定位

- **一个游离 skill**(不属于任何 plugin 套件),目录:`ten-step-learning/`(`SKILL.md` + `assets/template.html` + `references/`)。
- **输入** = 一个学习主题(+ 开场两问采集的学习画像);**输出** = 当前工作目录下的 `<主题>-十步学习.html`,单个自包含文件。
- **方法来源** = 五视角 STORM(斯坦福 STORM,检索增强的多视角调研)+ Rahul「四要素:一条路径、一次测试、一次压缩、一个反馈循环」,大刘融合成「学习 → 深化 → 记忆 → 回顾」的完整闭环,共十步、按顺序执行、逐环消费上游产物。
- **灵魂** = **闭环 + 逐环交接**。十步不是十段独立内容,而是一条线:前一步的产物是后一步的输入。严禁跳序、严禁让某步凭空生成而不消费上游。

## 何时触发 / 何时不触发

**正向触发**:用户想对一个**陌生主题**做**结构化、闭环式、可留存**的深度学习——"用十步学习法学 X / 系统学一下 X / 十倍速学 X / 用 STORM 学 X / 把 X 从零学到能和专业人士对谈 / 给我做一份 X 的完整学习 HTML/学习闭环"。

**反触发**:

1. **只是一个具体事实 / 一句话就能答的问题** → 直接回答,别启动重流程。
2. **要做的是 PPT / 竞品报告 / 正式文档等特定产物**(而非"学习一个主题")→ 交给对应 skill(guizang-ppt-skill / competitive-analysis-report / minimax-docx 等)。
3. **用户明确只要十步里的某一步**(如"只帮我出速查表""只跑五视角")→ 可只执行该步,不必强跑全程。

## 五阶段流程(严格按序)

### 阶段 0 · 开场两问,建立学习画像(唯一一次打断)

拿到主题后,**只问两个快问**,答完即全自动零打断:

1. **你的当前水平 + 想达到的深度?**（零基础 / 有点基础 / 有经验;目标是"能聊两句" / "能上手干活" / "能和专业人士对谈"——默认取"能和专业人士对谈"）
2. **你的角色 / 使用场景?**（用于第 3、5、6、7 步"以我的角色,我该做什么不一样的事"的个性化;若用户开场已给,则不必再问）

把两问答案凝成一句「学习画像」(如:*运营背景、想达到能与专业人士对谈、用于给团队做分享*),贯穿全程填入各步提示词的 `{{角色}}`/`{{水平}}`/`{{目标}}` 占位。第 7 步"2 小时核心 20%"的时间按原文写死 2 小时,不单独问。

### 阶段 1 · 研究方式(混合,按需真实联网)

- **必须真实联网的两处**:**第 1 步**(五视角取证,证据要真、可溯源)、**第 5 步**(真实资源筛选,书/课/社区必须是真实存在、尽量新的)。这两处的联网检索**一律通过仓库的 `web-access` skill** 完成(本仓库约定:所有联网操作必须走 web-access)。
- **靠模型推理的部分**:第 6–10 步是教学结构化(阶梯、核心 20%、题库、费曼、速查表),不需要联网,由模型基于前几步产物 + 自身知识生成。
- **检索强度自动判断**:主题越硬核/越前沿,检索越重;常识性主题可轻检索。宁可多查也别编造资源与证据。

### 阶段 2 · 顺序执行十步(逐字提示词见 `references/ten-step-prompts.md`)

按 1→10 顺序执行,每步做三件事:**跑该步提示词(已填主题与画像)→ 拿到完整原始产物 → 提炼学习结果**。每步都必须**显式消费上游产物**(如第 2 步吃第 1 步的五视角、第 3 步吃第 1+2 步、第 4 步评审第 3 步的简报……)。

十步与逐环依赖:

| 步 | 名称 | 消费的上游 | 输出(原始产物) |
|---|---|---|---|
| 1 | 五视角 STORM | 主题 | 5 位专家各自的立场/最强证据/独有洞察 |
| 2 | 矛盾图谱 | 步1 | 冲突对、最强/最弱证据、化解关键、共识、盲区 |
| 3 | 综合简报 | 步1+2 | 一段话总结 + 5 关键发现(带可靠性)+ 隐藏关联 + 行动建议 + 前沿问题 |
| 4 | 同行评审自检 | 步3 | 5 发现逐个 1–10 打分、最没把握项、过重视角、缺的第6视角、斯坦福教授评分 |
| 5 | 资源筛选 | 主题+画像 | 5 个真实资源(为何强/怎么用/花多久/一个关键点)+ 被高估的坑 + 一周路径 |
| 6 | 学习阶梯 | 主题+步3 | 5 级难度,每级 8 要素(名称/该懂什么/掌握长相/重点/里程碑/练习/常见错/自测题) |
| 7 | 2 小时核心 20% | 步3+6 | 核心 20% 概念 + 10 次课(目标/概念/练习/资源/预期)+ 每课 5 复习题 + 最终小项目 |
| 8 | 考到崩溃(材料化) | 步3+6+7 | **题库**:10 题分级(初/中/高/专家)+ 每题参考答案 + 评分标准 + 5 道终极挑战 |
| 9 | 费曼循环(材料化) | 步3 核心概念 | **分层费曼讲解**:大白话+生活例子讲透 + 逐个拆常见困惑点 + 一句话精确定义 |
| 10 | 一页速查表 | 全部 | 一句定义 + 短条目要点 + 3–5 真实例子 + 易错点 + 上场清单 + 5 快问快答 |

**第 8、9 步的材料化(关键)**:原文这两步是一问一答的交互对话。本 skill 是"一次性出静态 HTML",故把它们改为**生成可复用的学习材料**:第 8 步产出**题库**(用户日后可拿去自测),第 9 步产出**分层讲解**。HTML 里这两步"输入·提示词"展示的是**实际使用的材料版提示词**,并在末尾注明"原文为交互式版本"。

### 阶段 3 · 渲染进模板(只填内容,不改外壳)

读取 `assets/template.html`,把每个 `{{...}}` 占位符替换成生成好的 HTML 片段。**严禁改动 CSS / 侧边栏 chrome / JS**;所有内容片段必须复用模板已定义的组件类(`.persona`/`.viz`/`.ladder`/`.flash`/`.res`/`.prose`/`.takeaways` 等)。逐占位符对照与片段写法见 `references/template-guide.md`。

- **每步三栏语义**(填占位时严格区分,互不重复):
  - **输入**(`{{STEP_N_INPUT}}`)= 该步提示词(已填好主题与画像)+ 消费了哪些上游产物(用 `.upstream` 标签标注)。提示词放进 `.prompt-block`。
  - **输出**(`{{STEP_N_OUTPUT}}`)= 该步**完整原始产物**,`.prose` 排版,默认可折叠展开。
  - **学习结果**(`{{STEP_N_TAKEAWAYS}}`)= 从该步**提炼**的 3–5 条核心 takeaway / 认知跃迁,`<ul><li>` 列表,是"给人看的结论",**不是**原始产物的复述。
- **标志性可视化**(填进 `{{STEP_N_VIZ}}`,其余步该占位留空):
  - 第 1 步 → 5 张 `.persona` 卡片(角色/立场/最强证据/独有洞察)。
  - 第 2 步 → `.viz` 里一张 SVG 关系图:5 个视角为节点,冲突用红线连、共识用绿线连,并标注盲区。
  - 第 6 步 → `.ladder` 阶梯可视化(5 级,从下往上)。
  - 收尾 → `{{LOOP_DIAGRAM}}` 一张环形闭环 SVG(开局→吃透→检验→压缩 四象限,或十步绕圈)。
- **全量详尽**:每步都出完整产物,不截断;长产物靠折叠面板消化(输出默认展开、输入折叠、学习结果常驻)。
- **语言**:正文中文为主;专有名词/术语(RAG、retrieval practice、STORM 等)保留英文原词,首次出现加中文解释。
- **主题与画像**:把 `{{TOPIC}}`、`{{METHOD_INTRO}}`、`{{STEP_MAP}}`、`{{CLOSING_*}}` 一并填好(总览页 method_intro 说明这套方法是什么;step_map 生成 10 张 `.stepmap` 卡)。

### 阶段 4 · 交付

- 写出 `<主题>-十步学习.html` 到当前工作目录(主题做文件名安全化)。
- **不**另存 markdown(HTML 即唯一交付)。
- 交付时向用户一句话汇报:主题、跑了哪些步、联网检索了哪几处、文件路径,并提示"侧边栏点击任意一步可看该步的输入/输出/学习结果"。

## 完成判定(交付前自检)

- [ ] 开场只问了两个快问,之后全自动无打断。
- [ ] 十步全部执行且**逐环消费了上游产物**(不是十段孤立内容)。
- [ ] 第 1、5 步的证据/资源来自**真实联网**(经 web-access),资源真实可查、非虚构。
- [ ] 第 8 步是**题库+参考答案+评分标准+5挑战**、第 9 步是**分层费曼讲解**(材料,不是对话实录)。
- [ ] 每步三栏语义正确:输入=提示词、输出=原始产物、学习结果=提炼结论,三者不重复。
- [ ] 第 1/2/6 步与收尾有对应可视化;其余步 VIZ 占位留空。
- [ ] HTML 是单文件、`{{...}}` 占位符**全部**被替换(不残留)、侧边栏 12 项可切换、CSS/JS 未被改动。
- [ ] 视觉严格符合 DESIGN(sage 画布 / forest 侧栏 / 单一 chartreuse 强调 / 无阴影 / 4px&16px 双圆角 / Fraunces 仅 36px+)。
