# 农业项目统计技能参考文档

## 数据源说明

### 输入文件
**`2026 年电信与 AIoT 业务线 FP 项目毛利管控表 20260310.xlsx`**

默认读取 **`实际运营数据-崔哲`** 工作表（可配置）。

```python
# 初始化时指定工作表
stats = AgricultureStats(
    input_file=Path('input.xlsx'),
    output_file=Path('output.xlsx'),
    sheet_name='实际运营数据-崔哲',  # ← 变更此处即可切换
)
```

如需切换到其他工作表（如`实际运营数据-李陶`），修改 `DEFAULT_DATA_SHEET` 常量或传入 `sheet_name` 参数。

### 输出文件
**`农业项目群预算毛利表汇总表-26.2.28.xlsx`**

包含 4 个工作表：
- `2026年汇总毛利率` — 按核算科目汇总所有农业项目（当月在行+已结项）
- `当月汇总毛利率` — 当月在行项目的月度汇总
- `2026年项目明细数据` — 所有农业项目明细（9行/项目）
- `当月项目明细数据` — 当月在行项目明细

- **表头**：第 1 行

### 9 个核算科目（每项目9行）

1. 累计收入（NR）
2. 人工成本（成本１）
3. 差旅费（成本３）
4. 其他成本（成本３）
5. 累计成本
6. GP1毛利
7. GP1毛利率(%)
8. GP3毛利
9. GP3毛利率(%)

## 核心类：AgricultureStats

### 初始化

```python
from pathlib import Path
from scripts.agriculture_stats import AgricultureStats

stats = AgricultureStats(
    input_file=Path('输入文件.xlsx'),
    output_file=Path('输出文件.xlsx'),
    current_month=3,        # 当前月份（判断当月在行）
    year=2026,               # 统计年份
    keywords_path=Path('references/agriculture_keywords.md'),  # 可选
    sheet_name='实际运营数据-崔哲',  # 数据工作表（默认，可切换）
)
```

### 完整流程

```python
# 1. 加载数据并筛选农业项目
count = stats.load_data()
# 返回农业项目数量

# 2. 分类项目
current_month_list, year_list, closed_list = stats.classify_projects()
# - 当月在行：项目结束时间 > 上月末
# - 当年在行：项目结束时间 > 当年1月1日
# - 已结项：项目结束时间 <= 当年1月1日

# 3. 生成输出文件（4个工作表）
sheets = stats.write_output(current_month_list, year_list)

# 或直接运行完整流程
result = stats.run()
# {'total_projects': 20, 'agri_projects': 2, 'current_month_projects': 1, ...}
```

### 按核算科目汇总

```python
agg = stats.aggregate_by_category(year_list)
```

## 农业项目识别

### 关键字匹配规则

**包含任一关键字** → 农业项目：

```
农业, 农村, 农田, 种植, 养殖, 畜牧, 渔业, 农机,
种业, 农资, 农产品, 畜禽, 林业, 农场, 审计署, 兽医,
中监所, 全国畜牧总站, 乡村振兴
```

**排除关键字**（优先级更高）：

```
银行, 保险, 证券, 贷款, 融资
```

### 自定义关键字

编辑 `references/agriculture_keywords.md`，或初始化时传入 `keywords_path`。

## 项目分类规则

| 分类 | 条件 | 说明 |
|------|------|------|
| 当月在行 | 结束时间 > 上月末 | 如 2026-03-01 后结束 |
| 当年在行 | 结束时间 > 当年1月1日 | 如 2026-01-01 后结束 |
| 已结项 | 结束时间 <= 当年1月1日 | 2025年及之前结束 |

**注意**：当月在行 ⊂ 当年在行

## 注意事项

1. **读取模式**：使用 `read_only=True` 提高大文件读取速度，但不支持写入
2. **日期解析**：支持 `datetime` 对象、Excel序列号、字符串（`%Y-%m-%d`等）
3. **空值处理**：`#DIV/0!`、`#N/A` 等Excel错误值自动转为 0
4. **多工作表**：输入表有多个"实际运营数据"工作表时，自动遍历所有表
5. **关键字更新**：`references/agriculture_keywords.md` 可按需增删关键字
