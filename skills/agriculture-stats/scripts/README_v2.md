## 功能改进

相比 v1 版本，v2 版本的改进：

### ✅ 已修复的问题

1. **使用已存在的工作表** - 不再删除重建，而是更新现有工作表
2. **保留表头格式** - 字体、背景色、边框等完全保留
3. **保留合并单元格** - 项目编码、项目名称等列的合并单元格完全复制
4. **保留列宽** - 所有列的宽度保持不变
5. **保留公式** - 如果单元格包含公式，复制公式而非计算结果

### 📋 主要特性

- **智能判断**：自动查找并更新已存在的 `当月项目明细数据` 和 `2026 年项目明细数据` 工作表
- **完全清空数据区**：每次运行前完全清空工作表（包括表头），因为表头会按月份动态变化
- **重新复制表头**：从输入表完整复制最新的表头（包含动态增加的月份列）
- **完整复制**：复制输入表的所有格式和样式
- **准确筛选**：根据项目结束时间准确分类农业项目

## 注意事项

### 1. 关键字配置

当前使用的农业关键字较少（5 个），如需完整识别，请编辑：
```
.lingma/skills/agriculture-stats/references/agriculture_keywords.md
```

添加更多关键字，如：
```
农业
农村
农田
种植
养殖
畜牧
渔业
农机
种业
...
```

### 2. 日期格式

项目结束时间支持以下格式：
- `2026-03-31`
- `2026/03/31`
- Excel 日期格式

### 3. 工作表名称

脚本会查找以下名称的工作表：
- `当月项目明细数据`
- `2026 年项目明细数据`

如果不存在会自动创建。

### 4. 性能优化

对于大量数据（如 100+ 项目），建议：
- 使用 `read_only=True` 模式读取
- 批量操作而非逐单元格复制
- 考虑使用 pandas 进行数据处理

## 常见问题

### Q1: 为什么识别到的农业项目很少？
**A**: 当前只加载了 5 个基础关键字。请编辑 `agriculture_keywords.md` 添加更多关键字。

### Q2: 如何修改筛选的月份？
**A**: 修改脚本开头的配置：
```python
CURRENT_MONTH = 3  # 当前月份
LAST_MONTH_END = datetime(2026, 2, 28)  # 上月最后一天
```

### Q3: 能否同时更新汇总表？
**A**: 当前版本只更新明细表。如需更新汇总表（`2026 年项目毛利表`），需要额外编写汇总逻辑。

### Q4: 运行后数据格式丢失？
**A**: v2 版本已修复此问题。确保使用 `transform_data_v2.py` 而非 v1 版本。
